Route Story Studio · v0.3.0

Help and guided journey

Route Story Studio is built first for one straightforward job: turn an existing GPX or KML route into a polished poster.

  1. Import a GPX or KML route.
  2. Choose a colour, photograph or consent-based map background.
  3. Adjust layout, zoom, route styling and annotations.
  4. Export SVG, PNG or JPEG.

What the poster shows

The generated image shows distance, elevation range and, when available, duration. Elevation range means the highest point minus the lowest point represented in the route.

What the route summary adds

The route summary uses simpler wording such as Total climb, Elevation range, Highest point and Lowest point so you can quickly understand the route.

Advanced option

Google Maps link acquisition remains available as an advanced, experimental option. It is not needed for normal poster creation.
