# Route Story Studio v0.4.0 — Timelines and motion

## Summary

v0.4.0 extends Route Story Studio from route-poster composition into local-first route storytelling while preserving the v0.3 poster workflow.

## Added

- deterministic story-event model with bounded ordering and validation;
- timestamp-derived timelines with normalized route-progress fallback;
- narrative story moments anchored to route progress;
- privacy-bounded local photo waypoints with mandatory accessible descriptions;
- local decode/re-encode of story photos so source EXIF/XMP/IPTC metadata is not copied;
- project schema 3.0 with explicit migration from supported v0.3-era schema 2.0 projects;
- metadata-only project media references with referential integrity;
- separate IndexedDB retention of local prepared story-photo payloads;
- deterministic play, pause, seek and restart semantics;
- reduced-motion behavior that avoids animated traversal;
- rich story sequencing across story events and existing route annotations;
- self-contained portable HTML story export with escaped user content and restrictive `default-src 'none'` CSP.

## Compatibility

Existing GPX/KML → poster workflows remain supported. Existing schema 2.0 project files migrate deterministically to schema 3.0 with empty story state unless story data is subsequently authored. Unsupported project schemas fail closed.

## Privacy and security

Story authoring introduces no upload or network dependency. Story photographs are processed locally. Photo location/time are not inferred from embedded metadata. Portable story HTML permits only embedded `data:` images and contains no external script or network dependency.

The existing consent boundary for OpenStreetMap backgrounds and provider-based planned-route generation is unchanged.

## Assurance evidence

Release readiness requires all repository-required checks to pass, including:

- unit and negative tests for story events, persistence, media boundaries, playback and export;
- project migration and round-trip tests;
- built-site smoke testing;
- browser coverage across Chromium, Firefox and WebKit;
- accessibility regression testing;
- end-to-end authoring, local save/reopen and portable story export coverage;
- existing v0.3 poster workflow regression coverage.
