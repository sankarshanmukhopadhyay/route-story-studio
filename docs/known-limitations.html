Route Story Studio · v0.1.0

Known limitations

Version 0.1.0 deliberately focuses on one reliable workflow: GPX to shareable route image.

  • No geographic map background
  • No route geometry editor
  • No photo background or photo waypoint interface
  • No local project save and restore
  • No route animation
  • No Google Maps link-to-GPX conversion
  • No cloud synchronisation
  • No external elevation correction
  • Device-specific browser memory limits may vary
  • GitHub Pages cannot configure every desired HTTP response header

These capabilities are tracked in the roadmap. They are outside the v0.1.0 assurance boundary.
