Route Story Studio · v0.2.0

Known limitations

  • Route geometry cannot yet be edited.
  • Google Maps links cannot yet be converted into GPX.
  • Projects do not synchronise across devices automatically.
  • OpenStreetMap's standard tile service is best-effort and may be unavailable or blocked.
  • Map backgrounds require a network request and are not a local-only feature.
  • Offline map packages are not supported.
  • Only documented KML structures are interpreted.
  • External elevation correction is not provided.
  • Animated route export is not available.
  • Device-specific browser memory limits may vary.
  • GitHub Pages cannot configure every desired HTTP response header.

Use a solid colour or imported photograph when a fully local workflow or guaranteed background availability is required.
