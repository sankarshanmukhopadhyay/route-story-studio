Route Story Studio · v0.1.0

Privacy model

Local-first by design: GPX parsing, statistics, preview rendering and image export happen in your browser.

What the application does not do

  • No user account
  • No GPX upload
  • No analytics or behavioural tracking
  • No cloud storage
  • No map-tile request
  • No external routing or elevation request

What may still be visible

GitHub Pages, your browser and your network provider may process ordinary requests needed to load the application. The application itself does not send the contents of your GPX route.

How to verify

  1. Open browser developer tools.
  2. Select the Network panel and clear existing entries.
  3. Import a GPX file and edit the poster.
  4. Confirm that no request carries route coordinates or GPX content.

See the repository privacy statement for the formal project position.
