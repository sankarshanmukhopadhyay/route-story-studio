Route Story Studio · v0.2.0

Privacy model

Local-first by default: route parsing, statistics, projects, photographs, annotations and export happen in your browser.

Local-only modes

Solid-colour and photograph backgrounds make no map request. Projects saved in IndexedDB remain in the current browser, and portable project files are downloaded directly to the user's device.

Map mode

Map mode is optional and requires explicit consent. It sends requests for the visible route area to OpenStreetMap's tile service. Those requests include the website origin as Referer, the browser's normal User-Agent and ordinary network metadata. GPX, KML and project files are not uploaded.

What the application does not do

  • No account
  • No analytics or behavioural tracking
  • No route upload endpoint
  • No cloud project storage
  • No external elevation or routing request

How to verify

  1. Open browser developer tools and select Network.
  2. Use a solid or photograph background and confirm no map tile request occurs.
  3. Select map mode and confirm requests begin only after pressing the consent button.
  4. Confirm no request body contains route-file content.
