Route Story Studio · v0.3.0 development

Deploy the constrained resolver

The reference implementation is in gateway/ and is designed for Cloudflare Workers.

cd gateway
npx wrangler deploy

Required configuration

  • Set ALLOWED_ORIGINS to exact Route Story Studio origins.
  • Accept only maps.app.goo.gl input.
  • Permit only the documented Google Maps redirect hosts.
  • Retain the five-redirect and eight-second limits.
  • Do not log complete source or destination URLs.

Operational boundary

The gateway returns JSON redirect metadata only. It must not become a general URL fetcher, proxy, scraper, geocoder or routing service.
