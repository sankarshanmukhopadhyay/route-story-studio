Route Story Studio · v0.2.0

Security and availability

GPX is treated as untrusted input. The application applies admission, parsing, rendering and export limits to reduce resource-exhaustion and injection risks.

Controls

BoundaryControl
XMLReject DTD and entity declarations
Admission8 MB, 100,000 points and 2,000 structures
MetadataBound imported text lengths
RenderingSample route and elevation points before SVG construction
PNGPixel budget, timeout and scale limits
UICoalesce repeated renders and invalidate superseded imports
BrowserRestrictive Content Security Policy and no-referrer policy

Responsible reporting

Do not place private location data in a public issue. Follow the instructions in SECURITY.md when reporting a vulnerability.
