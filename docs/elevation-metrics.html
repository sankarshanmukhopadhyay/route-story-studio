ROUTE STORY STUDIO v0.3.0

Elevation metrics

Route Story Studio uses several related terms. They are not interchangeable.

Elevation gain

Elevation gain is the cumulative total of meaningful uphill changes along a recorded route. It is not calculated by subtracting the lowest point from the highest point. A route that climbs, descends and climbs again accumulates both climbs.

Estimated ascent

Estimated ascent is the same cumulative-climbing concept applied to a planned route or terrain-derived elevation profile. The word “estimated” signals that the value may depend on route sampling, terrain models and small elevation fluctuations. It is not evidence of ascent actually completed.

Elevation range

Elevation range is the highest elevation minus the lowest elevation represented in the route. It describes the route’s vertical span. It can be much smaller than cumulative ascent when a journey contains repeated climbs, and it can be large on a route that mostly descends.

Highest and lowest point

These are the maximum and minimum elevation values present in the imported route data. Their reliability is limited by the source file and the method used to obtain elevations.

Net elevation change

Net elevation change is finish elevation minus start elevation. A loop may have a net change near zero while still containing substantial cumulative climbing.

How the studio calculates ascent

In v0.3.0 the studio sums positive point-to-point elevation changes within each route segment. Dense or noisy terrain-derived profiles can overstate cumulative ascent. The route summary therefore distinguishes planned-route estimated ascent from recorded-track elevation gain, and presents elevation range separately.

How to interpret poster values

  • Use elevation gain as a cumulative climbing measure for recorded tracks.
  • Use estimated ascent as an approximate cumulative climbing measure for planned routes.
  • Use elevation range when you want highest point minus lowest point.
  • Do not treat any imported elevation value as survey-grade evidence.
