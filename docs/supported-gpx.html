Route Story Studio · v0.2.0

Supported GPX files

Version 0.1.0 supports common GPX 1.0 and 1.1 files containing recorded tracks or planned routes.

GPX contentSupport
GPX 1.0 / GPX 1.1Yes
Tracks and multiple tracksYes
Multiple track segmentsYes, boundaries are preserved
Planned routes and route pointsYes
ElevationOptional
TimestampsOptional
Vendor extensionsIgnored unless part of the supported core fields

Safety limits

  • Maximum file size: 8 MB
  • Maximum route points: 100,000
  • Maximum tracks, routes and segments: 2,000
  • DTD and entity declarations are rejected

Planned route versus recorded track: a planned GPX route describes an intended path. It is not evidence that the journey occurred.

Data quality

Distance, duration and elevation are calculated from the imported values. Route Story Studio does not correct elevation against an external terrain service. Missing timestamps mean duration may be unavailable.
