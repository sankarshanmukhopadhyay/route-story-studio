Getting started

  1. Choose a source. Review a map link, import GPX/KML, or open a project.
  2. Resolve only when needed. Map-link place resolution and routing are external and require explicit action.
  3. Confirm the route. Check type, format, point count and warnings.
  4. Shape the story. Work through identity, layout, background and annotations.
  5. Export or save. Download an image or keep a reusable project.

Use a solid or photo background for a fully local workflow. Provider routing and map tiles are separate consented network actions.
