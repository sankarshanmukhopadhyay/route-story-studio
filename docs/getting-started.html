Route Story Studio · v0.1.0

Getting started

Create a shareable route image in a few minutes. No account or upload is required.

  1. Load your route file. Select Choose a GPX or KML file, drag a file into the import area, or use the sample route.
  2. Check the summary. Review the route type, point count, segment count and distance. Read any import warnings before continuing.
  3. Add context. Enter a short title and optional subtitle such as the location, date or trip name.
  4. Choose the layout. Portrait works well for social sharing, square is compact, and landscape suits presentations.
  5. Adjust the design. Select metric or imperial units, colours, line width, elevation, duration and endpoint markers.
  6. Download. Use SVG for scalable artwork or PNG for immediate sharing.

Use the sample first

Select Use sample route to explore every control without finding a GPX file. Reset removes the current route and returns the studio to its initial state.

Nothing is uploaded

The application has no route upload endpoint. Choosing a file gives the browser temporary access so it can parse and render the route locally.
