Route Story Studio · v0.2.0

Getting started

You can first review a supported Google Maps directions link, or create and save a route story in a few minutes. No account or route upload is required.

Review a map link

Paste a supported directions link in the acquisition panel and select Review route intent. This extracts visible origin, destination, waypoints and travel mode locally. See Map-link review.

  1. Load your route. Choose GPX or KML, drag a file into the import area, open a project or use the sample.
  2. Check the summary. Review route type, source format, points, segments, distance and warnings.
  3. Choose a template. Use social, editorial, expedition or print layouts.
  4. Add context. Add a subtitle, route annotations and a solid, photograph or optional map background.
  5. Save your work. Save in the current browser or export a portable `.rssproj` project.
  6. Publish. Download SVG for scalable artwork, PNG for general sharing or JPEG for photo-led output.

Using a map

Selecting Map background reveals and focuses a disclosure panel. Press Consent and load map now to start the request. Export remains disabled until a valid map loads or another background is selected. See Map backgrounds for blocked-tile recovery.

Use the sample first

Select Use sample route to explore the studio without supplying personal route data.
