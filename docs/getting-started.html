ROUTE STORY STUDIO v0.3.0

Getting started

1. Import

Choose a GPX or KML file. Import is local and is the recommended starting point.

2. Shape

Select a layout, title, route style and background. Solid colour and photograph modes are fully local. Map mode requires explicit consent before OpenStreetMap tiles are requested.

3. Export

Download SVG, PNG or JPEG, or save a reusable local project.

Advanced Google Maps workflow

Open the collapsed Advanced section only when you need to reconstruct a planned route from a supported link and have the required resolver and provider credentials.
