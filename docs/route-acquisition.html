Resolve a map link into a planned route

External processing is opt-in. Reviewing a link is local. Geocoding and routing begin only after you choose a provider, enter credentials and press the relevant action.

  1. Paste a supported full Google Maps directions URL.
  2. Review origin, destination, waypoints and mode.
  3. Choose openrouteservice and enter your API key.
  4. Resolve named places and review every candidate.
  5. Build the confirmed planned route.
  6. Continue to the composition studio.

Evidence boundary

The resulting geometry is labelled as a reconstructed planned route. It cannot claim recorded-track status.
