ROUTE STORY STUDIO v0.3.0

Experimental route acquisition

Status: experimental and secondary.

The acquisition workflow can review supported Google Maps links, expand approved short links through a separately deployed resolver and use openrouteservice to reconstruct planned geometry.

It is hidden behind an Advanced disclosure because it depends on external infrastructure, API credentials and provider availability. Direct GPX/KML import remains the stable path.

Generated geometry is labelled as a reconstructed planned route and is not evidence of completed travel.

See short-link expansion, routing providers and interoperability evidence.
