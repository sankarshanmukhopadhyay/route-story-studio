# v0.4 final integration notes

## Authority boundaries

- `src/domain/story-timeline.js` owns canonical story-event validation and ordering.
- `src/story/story-session.js` owns bounded authoring-state mutation.
- `src/story/playback.js` owns deterministic playback state.
- `src/project/project-model.js` owns persisted project references and schema migration.
- `src/storage/indexeddb.js` retains browser-local project records and prepared story-media payloads.
- `src/export/export-story-html.js` owns the portable story artefact boundary.
- `src/app.js` orchestrates these capabilities and does not redefine their semantics.

## Revocation and cleanup

Removing a photo event revokes its media reference in the story session. Project autosave reconciles the browser-local story-media store by clearing the project's retained payload set and writing only payloads still referenced by the current authoring session. Deleting a project deletes both the project record and its local story-media payloads.

## Portability

`.rssproj` remains a bounded project/state artefact and carries media metadata/references rather than binary images. Prepared image binaries remain browser-local. The explicit **Export story HTML** action produces a self-contained portable presentation by embedding currently available prepared images as data URLs.

This split keeps ordinary project state bounded while making publication an explicit user action.
