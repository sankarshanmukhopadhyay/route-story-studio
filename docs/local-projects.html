Route Story Studio · v0.3.0 development

Save and reopen projects

A project keeps the route, current design choices and provenance together so the route story can be edited again.

Save in this browser

  1. Import a GPX or KML route.
  2. Choose the layout, colours, units and visible details.
  3. Select Save in browser.
  4. Use Open latest project the next time the studio is opened on the same browser profile.

Browser projects use IndexedDB. Clearing site data or using another device removes access to those saved projects.

Portable project files

Select Export project to download a .rssproj file. Use Import project to reopen it later or on another device.

Current project format: the project uses a versioned JSON container and can retain route-acquisition provenance and embedded background composition. Provider credentials are never included.

Project controls

  • Maximum project file size: 12 MB
  • Maximum route points: 100,000
  • Maximum annotations reserved by the schema: 500
  • Unsupported schema versions are rejected
