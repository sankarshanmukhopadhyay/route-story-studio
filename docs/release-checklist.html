v0.3.0 development assurance checklist

Route acquisition

  • Map-link review is local
  • Named places require candidate review
  • Coordinates bypass geocoding
  • Provider key never enters projects or exports
  • Generated route remains planned-route classified

Map zoom

  • Zoom remains within the nine-tile budget
  • Closer framing is labelled as potentially cropped
  • Zoom reload occurs only after consent

CI evidence

  • Unit, security and documentation checks pass
  • Browser acquisition flows use mocked external services
  • Accessibility checks pass
