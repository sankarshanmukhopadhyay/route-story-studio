v0.2.0 release checklist

Functional evidence

  • GPX and supported KML fixtures pass
  • Local and portable projects round-trip
  • Photo and map backgrounds work through their documented consent boundaries
  • Publication templates and route-relative annotations render
  • SVG, PNG and JPEG export are available

Map-provider evidence

  • The application sends a web-compatible Referer
  • Browser caching remains enabled
  • Tile count, concurrency, pacing, response size and timeout limits pass
  • HTTP 403 and blocked-tile images are rejected before export
  • OpenStreetMap attribution remains visible

Assurance evidence

  • Unit, security-policy and documentation checks pass
  • Static build and site smoke test pass
  • Playwright exercises Chromium, Firefox and WebKit
  • Automated accessibility checks report no serious or critical violations

Publication gate

  • Version, SBOM, changelog and release notes agree on 0.2.0
  • GitHub Pages deployment succeeds
  • Live GPX, KML, project, map-consent and export flows are verified
  • Known limitations remain visible
