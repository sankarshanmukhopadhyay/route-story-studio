Review before export

After a provider builds geometry, review its provider, travel mode, point count, generation time, warnings and intent hash. The application labels every acquired route as a reconstructed planned route.

GPX output

The default GPX uses a rte element because the file represents a planned route. An optional dense trk can be included for software that needs the provider geometry, but its metadata still states that it is reconstructed.

KML output

KML uses a LineString with start and finish placemarks. It contains no scripts, NetworkLinks or remote resources.

Provenance receipt

The JSON receipt records the source type, SHA-256 hash of canonical route intent, confirmed locations, travel mode, provider, generation time, geometry summary and warnings. API keys are never included.

Evidence boundary

These files describe a route calculated by a provider from confirmed intent. They are not evidence that anyone travelled the route.
