Route Story Studio · v0.3.0 development

Review a Google Maps directions link

This step recovers route intent only. It does not call a routing provider, create route geometry or claim that a journey occurred.

How it works

  1. Paste a supported full Google Maps directions URL.
  2. Select Review route intent.
  3. Check the recovered origin, destination, waypoints and travel mode.
  4. Review warnings before any future geocoding or routing step.

Supported in this increment

Link formBehaviour
Official directions URLs using origin and destination parametersParsed locally
Path-based /maps/dir/… URLsParsed locally where locations are exposed
Coordinate locationsValidated locally
Named placesRetained as unresolved place names
maps.app.goo.gl short linksRecognised, but not expanded until a constrained resolver is available

Security boundary

Only HTTPS links from an explicit Google Maps host allowlist are accepted. Private-network destinations, embedded credentials, unsupported hosts and links over 4,096 characters are rejected.

Evidence boundary

A shared map link usually describes intended travel. Even after a later provider generates geometry, the result must remain labelled as a reconstructed planned route rather than a recorded track.
