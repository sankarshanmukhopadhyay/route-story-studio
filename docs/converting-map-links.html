Route Story Studio · v0.3.0 development

Review a Google Maps directions link

Review is local. It recovers route intent but does not generate geometry.

Link formBehaviour
Official origin/destination parametersParsed locally
Path-based /maps/dir/…Parsed where locations are exposed
CoordinatesValidated and need no geocoding
Named placesRequire provider resolution
maps.app.goo.gl short linksExpanded through the configured constrained resolver after explicit action

Short-link expansion

Short links require a separately deployed resolver endpoint. The resolver follows approved Google redirects only; openrouteservice performs geocoding and route generation later. See short-link expansion.

After review

The provider panel appears only when the link exposes both an origin and destination. Continue there to resolve ambiguous places and build a planned route.
