Route Story Studio · v0.3.0 development

Supported KML

Route Story Studio can import common KML route geometry without sending the file to a server.

Supported geometry

KML structureBehaviour
LineStringImported as planned route geometry.
gx:TrackImported as recorded-track geometry, including aligned timestamps when present.
Point placemarksRetained as named waypoints for later composition features.
Multiple lines or tracksPreserved as separate route segments.

Safety limits

  • Maximum file size: 8 MB
  • Maximum route points: 100,000
  • Maximum KML features: 2,000
  • DTD and entity declarations are rejected

Not yet supported

Polygons, NetworkLinks, remote resources, embedded styles, tours and arbitrary HTML descriptions are ignored or rejected. KML does not automatically prove that a journey occurred; ordinary LineStrings are labelled as planned routes.
