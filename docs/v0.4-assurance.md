# v0.4 assurance contract

The v0.4.0 release is acceptable only when the repository can produce evidence for each proposition below.

| Proposition | Required evidence |
| --- | --- |
| Story ordering is deterministic | Unit tests for event normalization and rich sequence ordering |
| Existing v0.3 projects remain readable | Schema 2.0 → 3.0 migration tests |
| Photo references cannot dangle | Project-model negative tests |
| Story photos remain local by default | Media ingestion code path plus browser tests showing no required network dependency |
| Source image metadata is not copied | Decode/canvas re-encode implementation and media boundary tests |
| Playback works with and without timestamps | Playback/timeline unit tests |
| Reduced-motion users are not forced through animation | Playback reduced-motion test |
| Story state survives local save/reopen | Cross-browser end-to-end project persistence test |
| Portable story export does not execute authored markup | HTML escaping/security tests |
| Portable story export is network-free | CSP/export structure test (`default-src 'none'`) |
| v0.3 poster workflow remains usable | Existing GPX/KML, composition and SVG/PNG/JPEG browser regression suite |
| Authoring controls remain accessible | Axe serious/critical gate plus native keyboard-operable controls |

A workflow-green state is necessary but not sufficient by itself: the release decision relies on these tests corresponding to the stated propositions. Any evidence gap keeps the release candidate open rather than being inferred away.
